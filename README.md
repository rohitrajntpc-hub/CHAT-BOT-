# Nova AI — Modern AI Chatbot Interface

Nova AI is a modern, responsive, dark-themed chatbot interface designed to provide a clean and professional conversational experience.

The project focuses on building a polished frontend experience using vanilla HTML, CSS, and JavaScript, with an architecture that can later be extended with a real AI API and backend services.

## Overview

Nova AI provides a professional chatbot interface with a modern dashboard layout, conversation history, interactive chat experience, responsive design, and smooth UI interactions.

The current version is a frontend-only implementation and uses predefined responses for demonstration purposes.

## Features

- Modern dark-themed user interface
- Responsive layout for desktop and mobile devices
- Interactive chatbot conversation interface
- Sidebar with recent conversations
- New conversation functionality
- Chat deletion functionality
- Interactive prompt suggestions
- Typing indicator animation
- Auto-resizing message input
- Enter-to-send functionality
- Smooth UI transitions and hover effects
- Mobile sidebar navigation
- Clean and reusable frontend structure
